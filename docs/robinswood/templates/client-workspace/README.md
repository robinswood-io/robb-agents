# Workspace client public

Suivre le [guide de configuration](../../client-workspace-template.md) pour créer
un workspace avec des connexions et modèles choisis explicitement.

Ce dossier ne distribue aucun moteur, schéma ou exemple de routage automatique.
Les permissions, sources, modèles par défaut et critères de validation sont
configurés dans les réglages ordinaires du workspace.
