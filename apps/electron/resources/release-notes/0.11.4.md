# v0.11.4 — macOS Update Fallback Hardening

This maintenance release strengthens the macOS updater path for unsigned or ad-hoc-signed internal builds while preserving the standard signed updater path for Developer ID releases.

## Bug Fixes

- **Robust macOS update installation for internal builds** — when the installed app is not signed with a Developer ID certificate, Robb Agents now bypasses Squirrel’s strict same-signature installer and uses a detached, verified installer fallback. The fallback validates the downloaded archive with `codesign`, checks the expected version, backs up the current application, replaces the app, clears stale updater caches, and relaunches Robb Agents. Developer ID builds continue to use the normal `electron-updater` installation path.

## Breaking Changes

- None.
