# v0.12.10 — Autonomous context-limit continuation, local model privacy, and security hardening

## Features

- **Autonomous context-limit continuation** — Sessions reaching context limits automatically compact or transition to a fresh provider session boundary without interrupting execution with manual continuation prompts.
- **1M and 272k context window support** — Recognize full context windows for Claude Opus 5 / 4.7 / 4.8, Sonnet 5, Fable 5 (1M tokens), GPT-5.4 / Codex (272k tokens), and Mistral Vibe (262k tokens) in host context-management policies.

## Improvements

- **Local model confidentiality** — Enforce strict network isolation and zero external telemetry or web search leakage when running on local/sovereign model endpoints.
- **Compaction handoff alignment** — Align SDK compaction instructions with the 6-section operational summary contract and support bilingual/operational section headings.
- **Bounded objective handoffs** — Automatically bound large initial objectives (> 16k chars), long amendment histories, and sub-agent internal turns (`agent-message`, `auth-result`, `browser-fallback`, `automation`) during clean context-limit recovery.

- **Eliminate context-limit blocking prompts** — Remove `context-limit-next-step`, `clean-continuation-unavailable`, and `disabled-routing-clean-continuation-unavailable` interruptions in autonomous sessions so multi-step missions complete end-to-end.
- **RPC, WebUI, and SSRF hardening** — Harden workspace/source/skill RPC path validation, WebUI authentication, DNS-pinned SSRF protection in `web-fetch`, and subprocess environment sanitization.
