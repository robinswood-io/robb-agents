# v0.12.5 - Resilient sessions and production staging

## Improvements

- Keep local production staging on the production application identity and `~/.craft-agent` profile, with clean-source provenance and explicit post-install verification.
- Upgrade the pinned Bun packaging toolchain to 1.3.14 and strengthen Windows installer payload and process cleanup checks.
- Document the separate development, local production staging, and public GitHub Release promotion paths.

## Bug Fixes

- Continue unfinished assistant turns after commentary, tool activity, provider interruption, or application restart, while preserving terminal responses and bounding automatic retries.
- Detect final responses that still announce concrete remaining work and resume execution instead of treating the turn as complete.
- Respect iOS standalone PWA safe areas in the top bar and page layout.
- Preserve production data and channel selection when replacing the local production application.
- Make Windows atomic writes durable and isolate CI caches used by release validation.

## Breaking Changes

- None.
