# v0.12.6 - Reliable runtime recovery and offline Remote

## Features

- Add an opt-in encrypted offline vault to Remote with read-only snapshots of up to 10 recent chats, local search, text drafts and pins, plus a manually reviewed outbox that never sends automatically.

## Improvements

- Make Remote a responsive, accessible PWA across phones and tablets, with a privacy-preserving offline shell, immediate reconnect states, and user-controlled app updates.
- Open conversations at their latest message so active work is immediately visible.
- Update production and development dependencies while retaining the validated React 18, TypeScript 6, Pi agent, table, calendar, and panel compatibility contracts.
- Package the expected ripgrep binary layout for Windows installer validation.
- Align ChatGPT and Claude subscription authorization scopes with the current official Codex and pinned Pi SDK contracts.
- Reconcile legacy dependency and architecture branch histories after confirming that their changes are already integrated, superseded, or intentionally held behind current compatibility contracts.

## Bug Fixes

- Recover the local agent runtime bridge after stale sockets, unexpected exits, or failed health checks, with bounded restart attempts and sanitized diagnostics.
- Preserve structured handoff details when the runtime must continue work after a bridge recovery.
- Complete Google Gemini Code Assist OAuth token exchange and refresh with the official public installed-app client credential plus PKCE. Individual accounts are routed to the supported Google AI Studio API-key flow, while Code Assist OAuth remains available to licensed organizations and fails closed with actionable eligibility guidance.
- Add the required Codex OAuth originator and reject incomplete ChatGPT or Claude token responses instead of saving unusable credentials.
- Localize the default navigation and loading actions throughout the AI connection wizard instead of falling back to English labels.
- Replace Mistral Vibe's headless TUI setup launch with its official delegated ACP browser authentication flow; Vibe continues to own and store the resulting credential.
- Resolve the packaged window icon from Electron's external resources instead of looking inside the ASAR.
- Restore ESLint 10 rule-test compatibility and bare-domain link detection after dependency updates.
- Keep Remote pairing usable in short landscape and under the mobile keyboard, prevent focus from entering off-screen panels, and avoid TopBar collisions with Remote controls.

## Breaking Changes

- None.
