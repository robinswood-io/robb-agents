# v0.11.5 — Secure Remote Access & Resilient Autonomy

This release adds secure browser and mobile access to Robb Agents while making autonomous task execution, recovery, and interactive browsing faster and more dependable.

## Features

- **Secure Remote access from any browser** — pair a trusted device with a short-lived, one-time code, monitor its connection from the dedicated Remote Access screen, and continue working through sessions scoped to the selected workspace. (`9014155`, `ae7b214`, `2a17c0d`)
- **Durable autonomous task routing** — agents now select executable task nodes through an explicit routing policy, persist the decision, and resume interrupted work without duplicating completed steps. (`75d7f71`, `244391b`)

## Improvements

- **Faster, self-healing interactive browser** — text entry uses a single CDP insertion, fast click navigations are observed without race conditions, stale accessibility references recover once by semantics, and post-action diagnostics run concurrently. Security challenges can be handed to the user with a non-blocking `resume` wait. (`a9fe1d5`)
- **Reproducible Bun 1.3.10 toolchain** — local development, CI, package metadata, and release builds now share the same pinned Bun runtime and type definitions. (`47759ec`, `ba5f79b`)

## Bug Fixes

- **Strict Remote authorization boundaries** — remote devices are durable and workspace-scoped; every RPC request is revalidated against an explicit allowlist, revoked devices disconnect immediately, and expired or reused pairing codes are rejected. (`13e793e`, `ae7b214`, `2a17c0d`)
- **Safer OAuth callbacks and stable updates** — OAuth callback handling is hardened and update-channel selection remains pinned to stable releases for production builds. (`d887cfd`)

## Breaking Changes

- None.
