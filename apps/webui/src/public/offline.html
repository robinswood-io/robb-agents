Vous êtes hors ligne

Votre hôte Robb doit être joignable pour le direct et le pilotage. Si vous avez activé l’espace hors ligne chiffré, rechargez l’application complète pour retrouver le texte synchronisé.

Le cache public ne contient aucune donnée privée. Le texte libre opt-in reste chiffré séparément ; les champs structurés de fichiers, identifiants, outils et authentification sont exclus, mais le texte enregistré peut lui-même être sensible.
