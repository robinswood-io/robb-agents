# Verticale de référence — rapprochement opérationnel et financier

Cette mission matérialise le flux de référence Robb Agents : collecte ciblée, normalisation canonique, analyse d'écarts, proposition, validation humaine, mutations idempotentes dans deux systèmes, réconciliation et rapport de preuve.

Le paramètre `productivity_pack` accepte `googleWorkspace` ou `microsoft365`. Le graphe, les dépendances, les livrables et les critères d'acceptation restent identiques : seul le pack configuré change.

L'exécution externe reste volontairement fail-closed tant que les connecteurs, secrets, politiques et capacités correspondants ne sont pas installés dans le runtime hôte.
